# 📱 QR Code Maker 0.1 (விளக்க ஆவணம் & பயனர் கையேடு)

**QR Code Maker 0.1** என்பது பயனர் விரும்பும் உரை (Text) அல்லது இணையதள முகவரியை (URL) லோகோவுடன் கூடிய QR குறியீடாக (QR Code) மாற்ற உதவும் ஒரு பைத்தான் (Python GUI) பயன்பாடாகும். 

இச்செயலி **போச்சம்பள்ளி அரசினர் மகளிர் மேல்நிலைப்பள்ளி (GGHSS, Pochampalli)** தகவல் தொழில்நுட்ப மன்ற மாணவிகளால் (2024-2025) உருவாக்கப்பட்டது.

---

## 🌟 அம்சங்கள் (Features)

- 🔗 **உரை & URL ஆதரவு:** எந்தவொரு இணையதள முகவரி அல்லது உரையும் QR குறியீடாக மாற்றலாம்.
- 🖼️ **லோகோ சேர்க்கும் வசதி:** QR குறியீட்டின் மையத்தில் நிறுவனத்தின்/பள்ளியின் லோகோ படத்தைச் சேர்க்கலாம்.
- 📁 **Browse வசதி:** கணினியிலிருந்து லோகோ படங்களை எளிதாகத் தேர்ந்தெடுக்க Browse பொத்தான்.
- 💾 **தானியங்கி சேமிப்பு:** உருவாக்கப்பட்ட QR குறியீடு PNG வடிவில் உடனடியாகச் சேமிக்கப்படும்.
- 👁️ **உடனடி முன்னோட்டம் (Preview):** உருவாக்கப்பட்ட QR குறியீட்டைச் செயலியின் திரை நேரலையிலேயே பார்க்க முடியும்.

## 🛠️ தேவைப்படும் மென்பொருள்கள் (Prerequisites)

இந்த நிரலை இயக்க உங்கள் கணினியில் **Python 3.x** நிறுவப்பட்டிருக்க வேண்டும். மேலும் பின்வரும் பைத்தான் நூலகங்கள் (Libraries) தேவைப்படும்:

```bash
pip install qrcode pillow
```

*(குறிப்பு: `tkinter`, `os`, `sys` போன்ற நூலகங்கள் பைத்தானுடன் இயல்பாகவே வரும்).*

## 🚀 இயக்கும் முறை (How to Run)

1. இந்த களஞ்சியத்தை (Repository) பதிவிறக்கம் செய்யவும் அல்லது `QRCodeMaker.py` கோப்பைப் பெறவும்.
2. முனையத்தில் (Terminal / Command Prompt) நிரல் இருக்கும் கோப்பகத்திற்குச் செல்லவும்.
3. பின்வரும் கட்டளையை இயக்கி செயலியைத் தொடங்கவும்:

```bash
python QRCodeMaker.py
```

---

## 📖 பயன்படுத்தும் முறை (User Guide / Step-by-Step)

1. **Enter Text or URL:** QR குறியீடாக மாற்ற வேண்டிய உரை அல்லது இணையதள முகவரியை முதல் பெட்டியில் தட்டச்சு செய்யவும்.
2. **Enter your Logo Path:** 
   - `Browse File` பொத்தானைக் கிளிக் செய்து, QR குறியீட்டின் நடுவில் வைக்க விரும்பும் லோகோ படத்தைத் (Logo Image) தேர்ந்தெடுக்கவும்.
3. **File name:** சேமிக்கப்பட வேண்டிய கோப்பின் பெயரை (File Name) உள்ளிடவும் (எ.கா: `my_qrcode`).
4. **Create:** `Create` பொத்தானைக் கிளிக் செய்யவும்.
5. இப்போது QR குறியீடு உருவாக்கப்பட்டு, அந்த இடத்திலேயே திரையில் காட்டப்படும். மேலும் அது `.png` வடிவத்தில் சேமிக்கப்படும்.
